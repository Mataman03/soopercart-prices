# מחירי סופרמרקטים ל-SOOPERCART

כל לילה גיטהאב מוריד את קובצי המחירים שהרשתות מפרסמות לפי חוק שקיפות המחירים,
ושומר קובץ אחד קטן, `prices.json`, בענף `data`.

- `chains.js` – איך מורידים מכל אתר (שופרסל, טיב טעם, קרפור, רמי לוי, יוחננוף, ויקטורי)
- `run.js` – ההרצה הלילית: מוריד את הסניף של כל רשת ומכין את `prices.json`
- `stores.js` – כלי עזר: מוצא את סניפי הרצליה של כל רשת
- `.github/workflows/prices.yml` – מתי גיטהאב מריץ את זה

הרצה ידנית במחשב: `node run.js out`
